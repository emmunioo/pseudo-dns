Rejestracja pseudodomeny .lewyt

Nadaj swojemu serwerowi społeczności lewicowYT krótką nazwę, np. moj-serwer.lewyt, zamiast długiego adresu .onion. Rejestracja jest darmowa.

.lewyt

Podaj adres .onion, HTTPS albo oba. Bez portu przyjmowany jest port 2137.

Potrzebny tylko do pokazania pola, które musisz dodać do manifestu. Konto potwierdza GitHub przy wysyłaniu.

Przed wysłaniem
  1. Dodaj do manifest.json swojego serwera pole "dnsClaim": "github:TWOJ-LOGIN" — tak automat sprawdza, że serwer należy do Ciebie. Po rejestracji możesz je usunąć.
  2. Kliknij przycisk poniżej. GitHub poprosi o zalogowanie i pokaże wypełnione zgłoszenie — zaznacz oświadczenie i wyślij.
  3. Automat sprawdzi serwer przez sieć Tor i w ciągu kilkunastu minut odpowie w zgłoszeniu.

Rejestr: github.com/emmunioo/pseudo-dns · Wynik sprawdzenia na tej stronie jest wstępny — ostatecznie decyduje automat rejestru.
